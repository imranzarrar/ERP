# Software Requirements Specification — General Ledger, Receivables, Payables 2.0

> Generated by `scripts/build-gl-docs.mjs` from `docs/gl-ap-ar/source`. Do not edit; change the source and rebuild.

Version 1.0 / 2026-10-15. Satisfies the BRD (01). Each system requirement (FR) states what the system shall do, where it is implemented, and which test cases prove it (case ids resolve in `docs/test-cases/`).

## 1. System overview

A multi-tenant web application (React client, Node/Express API, PostgreSQL with row-level security). Documents (invoices, expenses, bills, vouchers, settlements) and manual journals post through one engine, `postJournalEntry`, into `journal_entries` / `journal_lines`. Subledgers, aging, statements and every report are queries over those lines. See the solution design (03).
